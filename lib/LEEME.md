# Conector de MySQL

Se incluye MySQL Connector/J 9.7.0 para conectar Java con MySQL mediante JDBC.

La información de licencia del fabricante se conserva en LICENSE. La biblioteca se obtuvo del repositorio Maven Central:

https://repo.maven.apache.org/maven2/com/mysql/mysql-connector-j/9.7.0/mysql-connector-j-9.7.0.jar

Documentación: https://dev.mysql.com/doc/connector-j/en/

Esta biblioteca pertenece a sus autores y conserva su licencia. El código del módulo de propietarios está en src/main/java.
